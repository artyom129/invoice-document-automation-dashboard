# Upwork Portfolio Entry

## Title

Invoice & PDF Data Extraction Dashboard with Excel Export

## Description

Developed a FastAPI-based document automation dashboard that converts PDF invoices into structured accounting data.

The application extracts vendor details, invoice numbers, dates, currency, subtotal, tax, and total values. It assigns a confidence score to each document, routes uncertain records into a review queue, detects duplicate invoices, stores processing history in SQLite, and exports clean datasets to CSV and formatted Excel reports.

## My contribution

- Designed the data-processing workflow
- Built PDF text extraction and parsing logic
- Implemented confidence scoring and duplicate detection
- Developed the FastAPI backend and responsive dashboard
- Added manual review and correction tools
- Created CSV and Excel exports
- Added REST API documentation and automated tests

## Technologies

Python, FastAPI, SQLAlchemy, SQLite, PyMuPDF, Pandas, OpenPyXL, Jinja2, HTML, CSS, Pytest
